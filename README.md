====================================================
  世界で一番どうでもいい戦争
  〜 最後のプリン争奪戦 〜
====================================================

「世界は終わる。プリンは終わらない。」

冷蔵庫の中の食材になって、最後のプリンを奪い合う
1〜4人対戦のパーティ対戦アクションです。
敵を全員倒しても、試合終了の瞬間にプリンを持って
いなければ負けます。


----------------------------------------------------
 遊び方（起動）
----------------------------------------------------

【かんたん】
  index.html をダブルクリックしてブラウザで開く。
  （Google Chrome / Microsoft Edge 推奨）

【うまく動かないとき（Python がある場合）】
  このフォルダで次を実行して、
      python serve.py 3472
  ブラウザで http://127.0.0.1:3472/ を開く。

※ インストール不要。通信も不要です（フォントだけ
   ネット接続時に見た目が良くなります）。
※ 音はブラウザの仕様で、画面を一度クリックするまで
   鳴りません。M キーで音の ON/OFF。


----------------------------------------------------
 操作方法
----------------------------------------------------

キーボード1人（ソロ）
  移動      : WASD / 矢印キー
  ジャンプ  : W / ↑ / Space
  すり抜け  : S / ↓
  攻撃      : J または Z
  必殺技    : K または X

キーボード2人で対戦するとき
  1P : 移動 A D / ジャンプ W / すり抜け S / 攻撃 F / 必殺技 G
  2P : 移動 J L / ジャンプ I / すり抜け K / 攻撃 ; / 必殺技 :
       （2P は矢印キーでの移動も可）

ゲームパッド（最大4人）
  移動 スティックか十字 / ジャンプ A / 攻撃 X / 必殺技 B・Y

共通
  下キー … 棚をすり抜ける／キッチンの「製氷ルート」に
           入る／電子レンジで温まる
  Esc・P … ポーズ　　M … 音 ON/OFF


----------------------------------------------------
 ルール
----------------------------------------------------

・試合終了の瞬間にプリンを持っていた者が勝ち。
  誰も持っていなければ、プリンの一番近くにいた者。
  それもいなければ 30 秒のサドンデス。
・プリンを持つと少し遅くなる。攻撃を受けると手放す。
・倒されても3秒で復活する。KO数は勝敗に関係しない。

★ 突然の出来事
  ・冷蔵庫が開く … 人間の手が入ってきて食材を外へ
    連れ去る。手は攻撃すれば追い返せる。
  ・停電 … 視界がほぼ無くなる。
  ・賞味期限が近い … 全員の体力が減っていく。
  ・人間がプリンを発見 … 皿に乗せられ、12秒以内に
    取り返さないと食べられて全員敗北。
  ・ボス「賞味期限切れのもやし」…倒した者に加護。

★ 冷蔵庫の外（キッチン）
  ・扉が開いている間だけ外に出られる。
  ・製氷ルート（青いホース）に下キーで入ると、
    冷蔵庫の一番上に戻れる。近道。
  ・電子レンジに入ると攻撃力と速度アップ。
    ただし、たまごは爆発する。


----------------------------------------------------
 キャラクター
----------------------------------------------------

🍅 トマト   バランス型
   必殺「トマト・スプラッシュ」跳び上がって着地、
   周囲に大ダメージ。自分もつぶれる。
   特性「つぶれる」やられると果汁が爆散し、周りを
   巻き込む。

🥚 たまご   一撃必殺型
   必殺「エッグ・インパクト」全力の突進。当たれば
   超ダメージ。3割の確率で自分が割れる。

🧀 チーズ   防御型
   必殺「とろけガード」無敵になり、触れた敵を
   とろとろに絡める。
   特性「熟成」生き残るほど強くなる（最大Lv5）。

🥬 キャベツ 高速型
   必殺「千切り乱舞」葉をまき散らす高速ダッシュ。
   特性「葉っぱダッシュ」二段ジャンプができる。

🥓 ベーコン 攻撃型
   必殺「ベーコン・ブレイク」油をまき、敵を
   ツルツル滑らせる。自分は滑らない。

 アイテム
